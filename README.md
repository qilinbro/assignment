# 英语课程作业管理系统

一个为英语课程（应用文 + 读后续写）设计的轻量作业管理工具。学生上传图片提交作业，助教在线批改，管理员统一管理。

## 功能

### 学生端
- 学号登录
- 提交作业 / 补交作业（自动根据截止时间判断）
- 上传作业图片（支持多张）
- 查看批改成绩和评语
- 申请修改（需管理员审批）

### 助教端
- 查看待批改列表（按等待时间排序）
- 连续批改模式（批完一份自动跳下一份）
- 看图批改（左侧学生作业图片，右侧打分+评语）
- 管理负责学生

### 管理员端
- 发布作业（应用文15分 / 读后续写25分）
- 自动生成提交链接（发到群里学生点开就能交）
- 全局数据总览（提交率、批改率、平均分）
- 未交名单
- 审批修改申请
- 学生管理

## 使用方法

直接用浏览器打开 `index.html` 即可运行，无需安装任何东西。

### 测试账号

| 角色 | 账号 | 说明 |
|------|------|------|
| 学生 | S001 ~ S008 | 输入学号直接登录 |
| 助教 | T001 ~ T003 | 输入工号直接登录 |
| 管理员 | admin | 需要输入密码 |

## 技术说明

- 纯前端单文件应用（HTML + CSS + JavaScript）
- 数据存储使用浏览器 localStorage（演示用）
- 正式上线需改为后端数据库，实现多用户数据共享
